How to use the free SEO tools

A short guide for new users. For each tool: what it is for, how to run it, how to read the result, and a small test you can try.

Open the free tools

Before you start

  • You do not need an account. Type a website address and press the button.
  • You get a free allowance of runs each day and each month. The tools page shows how many you have left.
  • Checking the same address again within 24 hours shows the saved result and does not use a run.
  • A check that fails, for example because the site did not answer, does not use a run.
  • Every result comes from a real check of the page or a public record. Nothing is estimated.

Instant SEO Audit

What it is for. A quick health check of one page. It gives a score, the main facts and the top problems to fix first.

How to use it

  1. Enter the full address of the page, for example https://example.com.
  2. Press Run Audit and wait a few seconds.

How to read the result

  • Score and grade: worked out from the problems found on the page. Fewer and smaller problems give a higher score.
  • Crawler access: whether search engines are allowed to read and list the page.
  • Security: whether the page loads over HTTPS.
  • Top issues: the problems found, most serious first. Start with Most important fix.

Try it

Run it on your home page. Fix the item shown as the most important fix, then run it again the next day and compare the list.

Domain URL Analyser

What it is for. A basic setup check for a whole site: age, security, technology and the files search engines look for.

How to use it

  1. Enter the domain or any address on the site.
  2. Press Analyse Domain.

How to read the result

  • Basic setup checks passed: four yes or no checks: HTTPS, a valid certificate, a robots.txt file and a sitemap.
  • Domain age: taken from the public registration record. This check uses one run of the Domain Age tool.
  • Sitemap page count: how many addresses the sitemap lists.
  • Technology stack: software that could be recognised from the page.

Try it

Run it on your own site. If robots.txt or the sitemap is missing, the guide Crawling and indexing basics explains what they do.

AIEO Analyser

What it is for. Checks the signals that AI answer engines such as ChatGPT, Gemini and Perplexity can read on your page. It does not measure how often they mention you: no engine publishes that.

How to use it

  1. Enter the address of the page.
  2. Press Check AI readiness signals.

How to read the result

  • Checks passed: four yes or no checks: an llms.txt file, structured data, organisation or person markup, and social preview tags.
  • Structured data types: the kinds of structured data found on the page.
  • Words on page: how much readable text the page has.

Try it

Run it on your home page and on your About page. The About page is the usual place for organisation or person markup.

SEO Page Analyser

What it is for. A closer look at one page: title, description, headings, text length, image descriptions and structured data. You can add a focus keyword.

How to use it

  1. Enter the address of the page.
  2. Optional: type the main keyword you want the page to be found for.
  3. Press Analyse Page SEO.

How to read the result

  • Title tag: its length in characters. About 50 to 60 fits in most search results.
  • Meta description: its length. About 120 to 160 characters is the usual target.
  • H1 tag: a page should have exactly one main heading.
  • Image alt coverage: the share of images that have a text description.
  • Keyword tags: if you typed a keyword, whether it appears in the title.

Try it

Pick a blog post or service page, type its main keyword, and check whether the keyword is in the title. The title generator can help you write a better one.

Domain Age Checker

What it is for. Shows when a domain was first registered, how old it is, when it expires and who the registrar is.

How to use it

  1. Enter the domain, for example example.com.
  2. Press Check Domain Age.

How to read the result

  • Registration date and age: from the registry's own public record.
  • Expires: the date the registration ends unless it is renewed.
  • Source: which public record answered. Some domain endings do not publish a date; the tool then says so instead of guessing.

Try it

Check your own domain and note the expiry date, so the renewal is never missed.

Domain Rank Checker

What it is for. Shows a public link-based score from 0 to 10 for a domain, and how many other sites link to it. The data comes from Open PageRank. It is not a Google score. This tool appears on the tools page only when it is switched on.

How to use it

  1. Enter the domain.
  2. Press Check Domain Rank.

How to read the result

  • Domain rank: 0 to 10. A higher number means more, and stronger, sites link to the domain.
  • Position: the domain's place among all ranked domains. A smaller number is better.
  • Referring domains: how many different sites link in.
  • Data date: when this data was last measured.

Try it

Compare your domain with one competitor. Look at the difference in referring domains, not only the score.

When your free runs are used up

  • After a few runs of a tool you are asked to confirm your email address. Open the confirmation link to keep using your free allowance.
  • When the daily or monthly allowance is used up, the page tells you which limit it is and how long until it refreshes. Access comes back by itself. If you do not want to wait, the page links to the AMK Digital Agency App.
