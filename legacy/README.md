## 🎯 What Is This?

A **zero-latency, self-contained client presentation layer** for AMK Digital Agency's AI-powered digital marketing suite. Built entirely from scratch using **pure HTML5, CSS3, and vanilla JavaScript** — no frameworks, no libraries, no build tools.

The demo showcases four core agency tools with a premium glassmorphism UI, fully interactive simulations, and a mobile-first responsive layout. Everything runs 100% client-side.

---

## 🏗️ Architecture

Built on three hand-crafted layers:

### 1. 🖥️ The Interface Layer
A unified dashboard written in **raw HTML5 + Vanilla CSS3**. Scales seamlessly from 4K monitors to mobile viewports with zero framework dependency.

- Custom **dark OLED glassmorphism** design system using CSS custom properties
- **Poppins + Inter + JetBrains Mono** typography (Google Fonts)
- Scroll-reveal animations, floating orbs, stagger transitions — all pure CSS keyframes + IntersectionObserver API

### 2. 🧠 The Client-Side Simulation Engine
A **vanilla JavaScript engine** powered by hardcoded JSON data objects. Delivers instant, structured demo outputs with zero API calls — works completely offline.

| Tool | What It Does |
|------|-------------|
| 🔍 **SEO Domain Audit** | 4-phase forensic crawl simulation with real-time console output |
| ✦ **Keyword & Title Generator** | Semantic cluster extraction mapped to 5 industry verticals |
| ✍️ **Article Writer** | Word-by-word streaming content blueprint via `setInterval` |
| 📚 **Docs Search Hub** | Auto-suggest search across 8 indexed knowledge base entries |

### 3. 🔒 The Security Layer
A lightweight frontend protection script:
- Disables right-click context menus
- Blocks F12, Ctrl+Shift+I/J/C, Ctrl+U, Ctrl+S
- Detects DevTools via window dimension differential → blurs page
