## 🎯 What Is This?

This is the **public-facing, zero-latency client presentation layer** for the **AntiGravity SEO Suite** — AMK Digital Agency's proprietary AI-powered digital marketing operating system.

The demo is a **100% static, self-contained single HTML file** (`index.html`) designed to showcase the suite's core tools to prospects and clients — with zero dependency on any backend server, Python environment, or database.

> **The actual production engine (Python backend, AI pipeline, database indexes) runs entirely on an isolated local workstation and is NOT included in this repository.**

---

## 🏗️ Architecture

The demo is built on **three core layers**:

### 1. 🖥️ The Interface Layer
A unified dashboard built with **HTML5 + Vanilla CSS3** media queries. Designed to scale seamlessly from 4K monitors down to mobile viewports without any CSS framework dependency.

- **Dark OLED glassmorphism** design system (custom CSS variables)
- **Poppins + Inter + JetBrains Mono** typography stack (Google Fonts)
- **Animated orbs, scroll-reveal, stagger transitions** via CSS keyframes + IntersectionObserver

### 2. 🧠 The Intelligence Simulation Engine
A **client-side JavaScript engine** that reads from hardcoded JSON objects inside the file, instantly displaying structured data that mimics live AI generations. No API calls. No latency. Works offline.

| Tool | Description |
|------|-------------|
| 🔍 **SEO Domain Audit** | 4-phase crawl simulation with per-section console output |
| ✦ **Keyword & Title Generator** | Semantic cluster extraction + conversion title blueprints |
| ✍️ **Article Writer** | Real-time word-by-word streaming from local content array |
| 📚 **Docs AI Hub** | Auto-suggest search over 8 indexed architecture documents |

### 3. 🔒 The Security Envelope
A **frontend script layer** that:
- Disables right-click context menus
- Blocks F12, Ctrl+Shift+I/J/C, Ctrl+U (View Source), Ctrl+S
- Detects DevTools open state via window dimension differential and blurs page content

## ⚙️ How to Run

**Zero setup required.** Simply open `index.html` in any modern browser:

```bash
# Option 1: Double-click index.html in File Explorer

# Option 2: From terminal
start index.html          # Windows
open index.html           # macOS
xdg-open index.html       # Linux
```

**For GitHub Pages deployment:**
1. Push this repository to GitHub
2. Go to **Settings → Pages**
3. Set source to **main branch → / (root)**
4. Your demo will be live at `https://[username].github.io/portfolio-demo/`
